## VTuber化の整理（今回の結論）

VTuberに必要なのは ①パーツ分けした絵 ②リグ ③入力 の3つ。
③は既存の MediaPipe 顔トラッキングと Gemini の音量で足りている。
①と②を Live2D Cubism でやると本物になるが、絵の分解に日数がかかるため、
今回は SVG の多層リグで近似した（見た目はLive2Dの8割、工数は1割）。

## P5: 表情のライブ監視と会話中の追注入

- Studio に `/vision` を追加。Mirage のカメラ映像・検出中の顔の矩形・笑顔/驚き/困惑スコア・距離・yaw をリアルタイム表示
  - Mirage が 100ms ごと（約10fps）に 160px JPEG＋スコアを `/studio/api/vision/live` へ POST
  - Studio はメモリ上の最新1件だけ保持し、SSE（`/api/vision/live/stream`）で即時配信（ポーリングなし）
  - 実測: 受信間隔 平均約82ms・表示までの遅れ 約100ms（偽カメラで確認）
  - Studio が落ちても展示は止めない
  - サイドバーに Vision を追加、ヘッダーのタイトルはパスに追従
- 表情の会話文脈注入を拡張
  - 開始時は従来どおり `buildVisitorContext`（笑顔/驚き/困惑＋急ぎ足）
  - 会話中も表情が安定して変わったら `injectContext` で追注入（1.5秒安定・最短10秒・同じ表情は1回）
  - 判定は `src/vision/expression.ts` の `moodOf()` に集約
- `useFaceDetection` に顔矩形（`faceBoxesRef`）と主対象インデックスを追加（ライブ表示用）
- **WebRTC 化**: `/vision` の映像を P2P に変更。SDP は Studio の HTTP メールボックス、映像はブラウザ間で直接。30fps の MediaStream をそのまま送り、TTFB は約1〜2秒。SSE は顔枠・表情用に継続し、未接続時は JPEG フォールバック
  - 実測（偽カメラ＋2ブラウザ）: `videoWidth=640, videoHeight=480, paused=false`、`Live / WebRTC` 表示を確認
  - 制限: 認証なし・TURNなし・最後に開いた `/vision` 優先（D-021）
- `tsc --noEmit`（Mirage/Studio）通過。API は curl、`/vision` はヘッドレスChromeで表示確認
